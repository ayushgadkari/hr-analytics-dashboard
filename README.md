# HR Analytics Dashboard

An interactive Power BI dashboard built to analyze employee demographics, performance scores, turnover rates, and key workforce metrics using HR Dataset v14.

## 📊 Project Overview
This project explores workforce data to uncover actionable insights regarding employee retention, salary distribution across departments, performance evaluations, and turnover drivers.

## 📁 Repository Structure
- `HRDataset_v14.csv`: The primary dataset containing employee records, performance metrics, and demographic details.
- `Power bi.pbix`: The Power BI dashboard file featuring interactive visualizations.

## 🔑 Key Metrics & Insights
- **Employee Demographics & Diversity:** Breakdown of employees by gender, marital status, and department.
- **Performance & Satisfaction:** Analysis of manager performance scores, engagement levels, and special projects involvement.
- **Attrition & Turnover:** Identification of trends associated with voluntary resignations and termination reasons.

## 🛠️ Tools & Technologies Used
- **Data Visualization:** Power BI
- **Data Analytics:** CSV / Data Modeling
- **Version Control:** Git & GitHub

## 🚀 How to View
1. Download the `Power bi.pbix` file and the `HRDataset_v14.csv` dataset.
2. Open the `.pbix` file using Power BI Desktop.
3. If prompted for data source paths, update the source link to point to your local copy of `HRDataset_v14.csv`.
